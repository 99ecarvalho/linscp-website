linscp 0.6.0 fills the remaining gaps in the Site Manager.

## What is new

- **Manage sites faster.** Search the site list with <kbd>Ctrl</kbd>+<kbd>F</kbd>,
  rename sites and workspaces in place, drag sites into folders, and clone a site
  to start a new one from it.
- **Colours and notes** on sites, so you can tell production from staging at a glance.
- **Paste a URL.** Type or paste a session URL such as
  `sftp://user@example.com:2222/var/www/` into the host name box and linscp splits
  it into its fields.
- **Anonymous FTP login**, and **S3 credentials read from the AWS environment**.
- **More on the Save and Login buttons**: Save As, Set Defaults, and the Login drop-down.
