linscp 0.7.0 is here — the first official release. After a run of 0.x previews,
linscp is out of pre-release: a fast, friendly app for moving files
between your computer and remote servers, with the same experience on Linux and
Windows.

## What you get

- **Side-by-side file management** — local and remote panels, with drag-and-drop
  copy, sync and edit-in-place.
- **Connect to anything** — SFTP, FTP, SCP, S3 and WebDAV.
- **Secure** — master password, encrypted saved sessions, host-key verification.
- **Two layouts** — Commander (dual-pane) or Explorer (single-pane).
- **Scriptable** — drive transfers from the command line using the same saved
  sites as the app.
