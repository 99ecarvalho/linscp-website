## Check your download

Each file above lists its SHA-256 checksum, the same value GitHub records for the
release. Compare it with the file you saved:

```sh
sha256sum linscp-*.AppImage
```

On Windows, in PowerShell:

```powershell
Get-FileHash .\linscp-*-setup.exe
```

The Windows builds are not code-signed yet, so SmartScreen may warn the first
time you run them.

## If you also use WinSCP

linscp uses the same configuration as WinSCP, so both programs see the same
sites and settings. To keep them apart, use the portable package. See
[configuration storage](../manual/preferences/storage-and-config/).

## Build it yourself

The source, build instructions and every past release are on
