## Look it up first

- The [manual](../manual/) covers installing, connecting, transfers,
  synchronization, scripting and security.
- Use the search box at the top of every page.

## Ask a question

Start a thread in
[GitHub Discussions](https://github.com/99ecarvalho/linscp/discussions). Say which
linscp version and operating system you use, and which protocol you connect with.

## Report a bug

Open an [issue on GitHub](https://github.com/99ecarvalho/linscp/issues). The most
useful reports include:

- the linscp version (**Help › About**) and your operating system;
- the steps that lead to the problem;
- a session log, with passwords removed. Turn logging on under
  **Preferences › Logging**, or run `linscp-cli` with `/log=<file>`.

linscp is not WinSCP. Please report linscp problems here, not on the WinSCP forum.

## Report a security problem

Do not open a public issue. Follow the
[security page](../manual/security/reporting-vulnerabilities/) to report
it privately.

## Help with translations

linscp uses WinSCP's translations. Interface texts that are new in linscp still
need translators; see the project's
[contributing notes](https://github.com/99ecarvalho/linscp).
