Report security problems **privately**, never in a public issue or discussion.
There are two ways:

- **On GitHub:** use the
  [private report form](https://github.com/99ecarvalho/linscp/security/advisories/new)
  (**Security** tab › **Report a vulnerability**).
- **By email:** write to [security@linscp.org](mailto:security@linscp.org).

The [security page](../../../security/) explains both step by step, what to put
in your report, what counts as a vulnerability and what happens after you send
it.
